# v0.16.0 — Online record, and fixes from the other port

## For players

- **Online record.** Every online match goes into your record: results, match history, rivals
  and replays ([Online play](../netplay.md#your-record-and-replays)).
- **Smoother venues with the HD packs.** Subway and Gun Hill Garage run at 60 fps again, and
  an online start no longer stalls in loading.
- **Updates** work from the launcher's download and for portable copies.
- **Volumes you saved stick.** Music and effects volumes from your profile reach the game
  after it loads (they went back to 85 on every restart).
- **Closing the window during a save** waits for the save to finish.
- **Data folders with accents or non-Latin letters** work on Windows.
- **When the game stops with an error**, it says why on every system and the launcher shows the
  message again at the next start until you dismiss it, so a message hidden behind the game
  window (Steam Deck Game Mode, macOS full screen) is not lost.
- **Widescreen HUD.** The combo call-out ("1ST COMBO MOVE") stays in one piece; the
  submission struggle meter ("TAP ANY BUTTON") stays with its fighter's health, top and bottom;
  without the widescreen menu pack, the song banner is no longer cut at the 4:3 edge.
- **Story cutscene SC04** keeps its sound with its picture.
- **Steam Deck and Linux** use less memory: texture decoding hands its buffers back to the
  system.
- **Setup** removes stray Python bytecode from its payload instead of refusing to install, the
  uninstall log says what was removed and what was kept, and Linux keeps the language pack's
  name.
- Everyone in an online match needs this version.

## Under the hood

- Most of these fixes are cherry-picked from the other port
  ([vyanhursky/DefJamFFNY-recomp](https://github.com/vyanhursky/DefJamFFNY-recomp)), one by one
  (D254); `scripts/other-port.py` lists what it adds after the last review.
- Toolkit `ee9c149` on the fork branch `defjam/upstream-fixes`: directory searches no longer run
  out after about 75 saves, thin compressed textures decode, and the widescreen HUD placement.
- `RECOMP_TEST_ISOLATE_CROWD` / `regress.py --isolate-crowd` takes the spectators and the
  time-seeded generators out of a pinned test fight, for the Steam Deck's `repeat` check (#98).
  The memory gate compares settled fight samples, reports scene changes apart, and
  `--only fight-cycles` plays five matches in one launch.

Setup compiles the player's verified supported USA Xbox dump locally; no game executable or
game assets are distributed.
