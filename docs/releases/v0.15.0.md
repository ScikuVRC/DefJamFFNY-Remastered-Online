# v0.15.0 — Invite codes

## For players

- **Invite codes instead of IP addresses.** Hosting shows an invite code (`DJ-XXXX-XXXX-...`)
  with a Copy button; send it to your friends and they paste it under Join. It holds your
  public address (once your router has opened the port) and your address on your home
  network, so a friend in the same house gets in too. No server is involved, and typed
  addresses still work ([Online play](../netplay.md#invite-codes)).
- Everyone in an online match needs this version: the lobby refuses players whose builds
  differ.

## Under the hood

- `src/hooks/netplay_invite.c`: the code is the port, up to two IPv4 addresses and a CRC-8 in
  Crockford base32 (case, spaces and dashes ignored; O reads as 0, I and L as 1; a typo fails
  the checksum). Joining tries the home-network address first, then the public one, three
  seconds each until the host answers; a connect now gives up after its timeout instead of the
  system's twenty seconds. `RECOMP_NETPLAY_JOIN` takes a code too.

Toolkit: `2c677a9` (unchanged). Setup compiles the player's verified supported USA Xbox dump
locally; no game executable or game assets are distributed.

## Tested

- Windows 11: unit tests (798, 13 of them for invite codes), release build.
- Two games on one PC, the joiner given a code whose home-network address was unreachable: it
  moved on to the next address, joined, and the match ran 30,000 steps in sync.
- The host's lobby shows the code and copies it.
