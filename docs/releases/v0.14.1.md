# v0.14.1 — Created fighters with the same name online

## For players

- **Two players whose profiles share a name can both bring their created fighter.** Before,
  the lobby refused the second "Created: MARC" and that player silently got a stock
  fighter. Now each game keeps its own player's profile as it is and shows the other
  player's as MARC2 (MARC3, ... for more); everyone keeps the earnings in their own
  profile ([Online play](../netplay.md#created-fighters)).
- Everyone in an online match needs this version: the lobby refuses players whose builds
  differ.

## Under the hood

- Saves sent between games carry their player's number (`FILE <player> ...`), so two
  profiles with one name no longer overwrite each other. The session save folder that a
  name clash used to fall back to is gone.
- `src/hooks/netplay_saves.c` renames a profile copy: the name in the save, its
  `SaveMeta.xbx` and its folder, and the save's signatures.
- CI runs on this repository (push and by hand); two native test fixtures build on Linux
  and macOS again.

Toolkit: `b578c7afbd008be1c3376ef5a4f89058ab42be86` (unchanged). Setup compiles the player's
verified supported USA Xbox dump locally; no game executable or game assets are distributed.

## Tested

- Windows 11: unit tests (785, with the native fixtures), release build; two games on one PC
  both on "Created: MARC" with different MARCs: each added the other's as MARC2 and a
  13,000-step fight stayed in sync, and the added copies were taken out afterwards.
- v0.14.0's Setup installed from the release into a new folder, and HD Fighters installed
  from the mod catalogue there.
- CI: all jobs, including the Windows, macOS and Linux Setup builds.
